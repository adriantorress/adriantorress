- **Dados e BI:** Power BI, DAX, Power Query, Excel, SQL e PostgreSQL
- **Automação:** Python, Playwright e integração de rotinas operacionais
- **Desenvolvimento:** Python, Flask, Flet, APIs, testes e migrations
